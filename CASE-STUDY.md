# Case Study: FloodSpy
## Problem
People in a flood need a place to see water and to say what they see. A strategy doc grew faster than the app.
## Approach
A Next.js page with three tools and Supabase routes that require a user for reports. The overview doc was left in place and was not treated as shipped scope.
## Result
Map, report, and alerts exist. Two commits, last touched 2025-05-03. No tests. No root README until this docs pass.
## What I'd do differently
I would mark the overview as a vision on the day the MVP page shipped, so a later reader does not think SMS and prediction models are in the build.
## Metrics
- Time to first working version: Two commits, last on 2025-05-03.
- Total AI spend: Not recorded.
- Features shipped: Map, alerts, and authenticated reports are in the tree. The overview's later phases are not.
