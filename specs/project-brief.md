# Project Brief: FloodSpy

## Vision
The running app is a Next.js map, a report form, and an alerts list. The overview doc also promises SMS, predictive models, and planner tools. Those were not found as code in this pass.

## Target User
A signed-in resident submitting a flood report, and a reader of the map and alerts. Broader personas in docs/project-overview.md are not implemented here.

## Success Criteria
- [ ] A signed-in user can open the map, submit a report, and see alerts.
- [ ] An unsigned request to create a report is rejected by the route.

## Out of Scope
- SMS, predictive flood models, and city-planner tools from docs/project-overview.md. Not found as implementation in this pass.
- A test suite.
